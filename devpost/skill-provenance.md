# Devpost Learn Skill Pack provenance

Official source: https://github.com/challengepost/learn-ai-basics

Installed revision: `a0f065781873e8a7ed9a9a705a8dafa6a0810439`.

Six official skills, templates and references are installed locally under `.agents/skills/`. The installed instruction package is excluded from application commits; project-specific scope, PRD, spec and build records are included in `devpost/`. This avoids treating templates as project work or redistributing the vendor bundle as original application code.

Reinstall official current pack if desired: `npx skills add challengepost/learn-ai-basics --all -y`. For this project's original instructions, use the exact revision above rather than assuming current main is identical.

Applied instructions: 1-start for the real learner profile; 2-scope for bounded problem definition; 3-prd for behavior, states and criteria; 4-spec for components/data/verification; 5-build for usable slices, mechanical verification, local checkpoints and offline app map. Review checkpoints are preserved as incomplete where participant review has not happened. 6-ship remains pending; final submission prose and personal survey answers belong to the participant.
